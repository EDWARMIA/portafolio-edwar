QA MANUAL · API · AUTOMATIZACIÓN

Pruebas QA — Toolshop

Verificación de una tienda online mediante pruebas manuales, de API y automatizadas, con documentación de casos, defectos y evidencias.

Playwright TypeScript Postman Node.js
HALLAZGO PRINCIPAL

Pérdida silenciosa de productos en el carrito (Race Condition).

El problema: si el usuario agrega un producto y hace clic rápido en otro, la web cancela la petición al servidor antes de que termine de guardarse.

El impacto: el cliente llega a pagar creyendo que tiene 3 productos y solo encuentra 1, sin que la página le muestre ningún aviso de error.

Trabajo realizado
Plan de pruebas, casos en Gherkin, documentación de defectos y pruebas de API con Postman: respuestas 200, 201 y 401, encadenadas con token e ID del carrito.
Alcance
Autenticación, catálogo y carrito. Automatización con Playwright y TypeScript: agregar tres productos con 1, 2 y 3 unidades, eliminar uno y comprobar su ausencia.
Entregables
Documentación, colección de Postman, prueba automatizada y capturas. Evidencia de ejecución: 1 prueba de carrito aprobada.
Ver proyecto en GitHub ↗

Aplicación evaluada: Practice Software Testing. Proyecto de práctica para portafolio; la tienda no fue desarrollada por mí.
